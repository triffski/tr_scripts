# Scripts 'n stuff

Somewhere to store random scripts and whatnot. Everything was made for my own use and is provided as-is, without warranty. 

Read the docstrings for more info, back up your files first and don't blame me if you didn't and something goes wrong! :)

| Name | Description |
|------|-------------|
| `album-artwork` | Scan a music library to identify files with no artwork, promote images found in album folders to album art, and extract art from music files to a sidecar. |
| `exif` | Harvest metadata from downloaded Facebook, Instagram and Flickr archives and write it back into the photos or XMP sidecars, ready for Immich. |
| `immich` | Immich API helpers for tasks that would be very tedious otherwise - source/album tagging, untagging, culling empty albums, library counts. |
| `geo` | Extract data from a Google Maps 'Takeout' for use with OsmAnd, Organic Maps etc. |
| `games` | Single-file web tools for games - currently MW4 DMZ Progress Tool, a stash, FOB and crafting tracker. |

Music tools, including the Ableton themes installer, now live in [tr_musictools](https://github.com/triffski/tr_musictools).
